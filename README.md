# livresgourmands.net — Projet final PWA (420-WA6-AG)

## Description du projet

**livresgourmands.net** est une plateforme de commerce électronique spécialisée dans la vente de livres de cuisine, adaptée à tous les niveaux : débutants, amateurs et chefs.

Le site se distingue notamment par :

* La gestion de listes de cadeaux personnalisées ;
* La collecte et la validation des avis et commentaires des clients ;
* L'intégration d'un module de paiement en ligne sécurisé.

---

## Étape 01 — Objectifs

Cette première étape consiste à établir les fondations du projet à travers l'analyse et la modélisation du site.

Les objectifs sont les suivants :

* Élaborer un diagramme de cas d'utilisation représentant les principaux acteurs du système : Internaute, Client, Ami, Éditeur, Gestionnaire, Administrateur et Prestataire de paiement ;
* Élaborer une première ébauche du diagramme de classes représentant les principales entités du système : Ouvrage, Client, Commande, Panier, ListeCadeaux, Avis, Commentaire, etc. ;
* Mettre en place le dépôt GitHub et organiser la structure de base du projet.
